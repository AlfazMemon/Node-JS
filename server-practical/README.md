# Node.js HTTP Server 🚀

A basic HTTP server built using Node.js.

## 🛠️ Technologies

* Node.js
* JavaScript
* HTTP Module

## ▶️ Run

```bash
node server.js
```

Open in browser:

```text
http://localhost:1234
```
