# HTML with Node.js 🚀

A simple project demonstrating how to serve an HTML webpage using **Node.js and Express.js**. The webpage includes CSS styling and JavaScript functionality.

## ✨ Features

* HTML webpage with modern styling
* CSS gradient background and responsive layout
* Interactive button using JavaScript
* Express.js static file serving
* Simple and beginner-friendly project

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Node.js
* Express.js

## 📁 Project Structure

```text
HTML-with-NodeJS/
├── public/
│   └── index.html
├── server.js
├── package.json
└── README.md
```

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Open the project folder**

```bash
cd HTML-with-NodeJS
```

**3. Install dependencies**

```bash
npm install express
```

**4. Start the server**

```bash
node server.js
```

**5. Open in your browser**

Visit: http://localhost:1234
