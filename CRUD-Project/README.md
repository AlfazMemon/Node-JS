# Product CRUD API 🚀

A simple REST API built using Node.js, Express.js, and the File System module to manage product data stored in a JSON file.

## 🛠️ Technologies Used

* Node.js
* Express.js
* File System (`fs`)
* JSON

## ✨ Features

* Fetch all products
* Add new products
* Delete products by ID
* Store data in `db.json`

## 🔗 API Endpoints

| Method | Endpoint             | Description      |
| ------ | -------------------- | ---------------- |
| GET    | `/`                  | Welcome message  |
| GET    | `/products`          | Get all products |
| POST   | `/add`               | Add a product    |
| DELETE | `/deleteproduct/:id` | Delete a product |
